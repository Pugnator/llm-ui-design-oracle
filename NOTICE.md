# Notice — third-party material

This repository is public. What follows is a precise account of what in it is
original and what is not, so the position is legible rather than assumed.

## Original

The rules, their rationales, review tests, the conflict analyses, the
anti-pattern catalogue, the checklist, the contract, and **Appendix A of
`UI_ORACLE.md`** are original text written for this repository.

The figures in `img/` are generated by `tools/make_figures.py` in this
repository. No third-party images, icons or fonts are included or hot-linked.

## Microsoft documentation

Rules in §17 (typography), §19 (colour) and §20 (accessibility) quote
published specifications from Microsoft Learn — the Windows type ramp, the
legibility floors, the 4.5:1 contrast ratio, the text-scale range and similar.

These are quoted **exactly**, because paraphrasing a specification destroys
it, and each is attributed with a link to the page and the page's own
`ms.date`. See `UI_SOURCE_MATRIX.md` for the full list with dates and
verification status.

If this repository is redistributed in a context with stricter requirements,
check the current terms on the Microsoft Learn pages themselves; they are
linked from every rule that uses them.

## Books

Three books inform the interaction-design rules:

- Alan Cooper, Robert Reimann, David Cronin, Christopher Noessel — *About
  Face: The Essentials of Interaction Design*, 4th ed.
- Jeff Johnson — *Designing with the Mind in Mind*, 3rd ed.
- Don Norman — *The Design of Everyday Things*, revised ed.

**No substantial portion of any of them is reproduced here.** What appears is:

1. **Restatement.** Appendix A summarises what each book contributes, in this
   repository's own words. Six longer passages that appeared in early drafts
   were deliberately rewritten as restatement rather than quotation.
2. **Short quotations for commentary.** Single sentences or phrases, each
   attributed to author, work and chapter, retained only where the exact
   wording carries the distinction being drawn — for example Norman's
   separation of affordances from signifiers, where a paraphrase blurs the
   very point.

The books are **not** included in this repository and are not required to use
it; that is what Appendix A is for.
